Eight UI kits, on their own components

Each kit is built from its own package and opened in the editor as it ships. Turn it, try it on your own app, and take its design system with you in that kit's own names.

  • Tailwind CSSUtility classes: no components; the theme is CSS variables you can override
  • daisyUIComponent classes on top of Tailwind: no JavaScript, works in any framework
  • shadcn/uiReact components copied into your repo: you own the source, it is not a dependency
  • BootstrapComponent classes, no build step needed: the widest-installed CSS framework there is
  • Material 3Google's design system: 47 colour roles derived from ONE seed, plus web components
  • Radix ThemesReact components with a real theming API: but one that takes CHOICES, not values
  • MantineReact components: its variables are public, its class names are build hashes
  • Ant DesignReact components with the styles generated at runtime: no stylesheet to import, a theme object instead
