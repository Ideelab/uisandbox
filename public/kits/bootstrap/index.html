Bootstrap theme editor

Component classes, no build step needed: the widest-installed CSS framework there is. UISandbox builds Bootstrap 5.3.8 from its own package and opens it in the editor: six screens in Bootstrap's own components and its own defaults. Turn the brand, the type, the spacing and the corners, and every component follows. Nothing to install, nothing uploaded.

What you take with you

Export writes Bootstrap's design system in Bootstrap's own names, starting from what you see:

  • _custom.scss: Bootstrap's Sass entry, for the brand it compiles in
  • theme.css: the variables, in Bootstrap's own names, as the knobs left them
  • install.md: where each file goes, step by step
  • MANIFEST.md: what could not be done, said rather than substituted
  • DESIGN.md: the design system for people and agents: colours, type, spacing, what each is for
  • .claude/skills/design-system/SKILL.md: for Claude Code, Cursor or Codex: build the next screen in Bootstrap's own classes
  • tokens.json: W3C design tokens, which Tokens Studio and Figma variables import

On your own app

If your app runs on Bootstrap, the sandbox recognises it from the rendered page and writes the design system in Bootstrap's names from your app's own values. What you turned on the kit comes with you. The quickest way in is the one where nothing leaves your machine: run npx uisandbox-mcp open in your project, or ask your agent to "open this app in UISandbox". How it works.
